# NEXPLAY — prototipo de portal de videojuegos

## Probar en tu ordenador
1. Descomprime `nexplay-portal.zip`.
2. Abre `index.html` con Chrome, Firefox, Edge o Safari.
3. Busca juegos, filtra categorías, guarda favoritos y abre el perfil.
4. `Neon Dash` es una pequeña demo jugable incluida.

## Publicar gratis con GitHub Pages
1. Crea una cuenta en https://github.com/ si no tienes una.
2. Crea un repositorio público nuevo, por ejemplo `nexplay`.
3. Sube `index.html` a la raíz del repositorio (botón **Add file → Upload files**).
4. En el repositorio, entra en **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**; elige `main` y `/(root)`, y guarda.
6. Espera a que termine el despliegue. GitHub mostrará la URL pública en la sección Pages.

## Importante
- Esta es una demo front-end, no un servicio completo con cuentas online.
- El perfil y los favoritos se guardan solo en el navegador mediante localStorage.
- Los demás juegos son fichas de ejemplo; no son juegos completos ni están integrados.
- Para incluir juegos de terceros, comprueba que su licencia permite redistribuirlos o incrustarlos. No copies archivos ni uses marcas/logos ajenos sin permiso.
- No incluye anuncios ni genera ingresos todavía.
- No recopila contraseñas ni información personal en un servidor. Para cuentas reales haría falta backend/autenticación, además de revisar privacidad, seguridad y normativa aplicable.
